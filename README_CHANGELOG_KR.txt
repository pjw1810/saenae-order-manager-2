사내 발주 관리 - 요청 기능 반영

변경 사항
1. 표에서 '번호' 열을 제거했습니다.
2. '납품 완료' 버튼을 추가했습니다. 표에서 품목을 선택하고 누르면 확인 후 해당 발주가 발주 내역에서 삭제됩니다.
3. 발주 등록 및 수정 화면의 모든 입력값을 선택 입력으로 변경했습니다.
   - 품번, 품명, 수량, 납기일, 거래처, 발주일 모두 공란으로 저장할 수 있습니다.
   - 수량을 입력하는 경우 양의 정수만 허용합니다.
   - 날짜를 입력하는 경우 YYYY-MM-DD 형식이어야 합니다.

설치/적용
1. 기존 메인 PC의 발주 데이터와 backups 폴더를 먼저 백업하세요.
2. 이 ZIP의 파일 전체를 GitHub 저장소에 반영하세요. 특히 app.py와 .github/workflows/windows-build.yml을 포함합니다.
3. GitHub Actions에서 Windows 빌드를 실행하고 성공한 새 설치 파일을 받으세요.
4. 메인 PC와 직원 PC 모두 새 버전으로 업데이트하세요.
5. 데이터베이스 파일(orders.sqlite3)은 삭제하거나 덮어쓰지 마세요. 기존 데이터는 유지됩니다.

주의
'납품 완료'는 요청에 따라 해당 발주를 실제 데이터베이스에서 삭제합니다. 삭제 후에는 프로그램에서 복구할 수 없으므로, 확인 창에서 내용을 확인하고 진행하세요. 별도의 납품 완료 이력은 저장하지 않습니다.

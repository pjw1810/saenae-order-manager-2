Order Manager - 최신 수정 내역

이번 버전 변경 사항
1. 발주 표의 행과 열에 연한 회색 경계선을 추가하고 헤더와 데이터 영역을 구분했습니다.
2. 표의 모든 데이터 및 헤더를 가운데 정렬했습니다.
3. 표에 표시되는 발주 수량은 천 단위 쉼표 형식으로 표시합니다. 데이터베이스에는 정수로 저장됩니다.
4. 엑셀 내보내기에서 수량을 숫자 셀로 저장하고 천 단위 표시 형식을 적용했습니다.
5. '납품 완료'를 납품 수량 입력 방식으로 변경했습니다.
   - 현재 발주 수량을 입력 창에 표시합니다.
   - 실제 납품 수량을 입력하면 해당 수량만큼 기존 발주 수량을 차감합니다.
   - 일부 납품이면 기존 발주 정보와 납기일, 거래처 등을 유지하고 잔여 수량만 갱신합니다.
   - 납품 수량이 현재 발주 수량 이상이면 전량 납품으로 처리하여 해당 발주를 삭제합니다.
   - 0, 음수, 빈 값, 정수가 아닌 값은 허용하지 않습니다.
6. 납품 처리는 Flask API에서 SQLite BEGIN IMMEDIATE 트랜잭션으로 수행하여 동시 접근 시 수량 차감/삭제가 원자적으로 처리되도록 했습니다.
7. 앱 창 및 설치 바로가기 이름은 Order Manager를 유지합니다.

기존 데이터 호환 및 적용
1. 기존 orders.sqlite3 데이터베이스 구조를 변경하지 않습니다.
2. 기존 데이터베이스 파일과 backups 폴더를 반드시 백업하세요.
3. ZIP의 전체 내용을 GitHub 저장소에 반영하고 GitHub Actions에서 Windows 설치 파일을 빌드하세요.
4. 빌드된 OrderManager_Setup.exe를 메인 PC와 직원 PC에 설치하세요.
5. 기존 orders.sqlite3 파일은 삭제하거나 덮어쓰지 마세요.

검증 범위
- app.py Python 문법 검사 완료
- Windows 설치 및 사내 LAN 다중 PC 실환경 테스트는 수행하지 않았습니다.
- 납품 API의 실제 DB 통합 테스트는 현재 실행 환경에 Flask/PySide6가 설치되어 있지 않아 수행하지 않았습니다.

발주 관리 프로그램 - 초기 제작본

[포함 기능]
- LAN 내 여러 PC에서 발주 등록/수정/삭제
- 메인 PC의 중앙 SQLite DB에 저장
- 클라이언트가 2.5초마다 서버와 동기화
- 품번/품명/거래처/상태 필터 및 전체 검색
- 표 헤더 클릭으로 정렬
- 납기 1일 이하 빨강, 2~3일 주황 강조
- 현재 필터/정렬 결과를 Excel(.xlsx)로 내보내기
- 진행중/완료 상태 관리

[중요: EXE 및 설치 파일 만들기]
이 프로젝트는 Windows용 빌드 스크립트를 포함합니다. 현재 전달된 파일은 소스 프로젝트이며,
Windows EXE는 Windows PC에서 build_windows.bat를 실행해야 생성됩니다.
빌드 PC에만 Python이 필요하며, 완성된 프로그램을 사용하는 사내 PC에는 Python 설치가 필요 없습니다.

1. Windows 10/11 64비트 PC에 Python 3.11 설치 (빌드용 PC만)
2. 프로젝트 폴더에서 build_windows.bat 실행
3. dist\SaenaeOrderManager\SaenaeOrderManager.exe 생성 확인
4. NSIS 설치 후 installer.nsi를 NSIS에서 Compile
5. SaenaeOrderManager_Setup.exe를 각 PC에 설치

[최초 실행 설정]
1. 메인 PC에서 프로그램 실행
2. 상단 '이 PC를 메인 서버로 사용' 체크
3. '연결 설정 저장' 클릭
4. 메인 PC의 사내 IP 주소 확인 (예: ipconfig 명령의 IPv4 주소)
5. Windows 방화벽에서 TCP 8765 포트 허용 (사내 개인 네트워크에서만 허용 권장)
6. 다른 PC에서 프로그램 실행 후 '서버 주소'에 메인 PC의 IPv4 주소 입력
7. '연결 설정 저장' 클릭
8. 연결 상태가 '연결됨'으로 표시되면 사용 가능

[메인 PC 주의]
- 메인 PC는 발주 데이터를 보관하고 API 서버 역할을 하므로 업무 중 켜져 있어야 합니다.
- 메인 PC의 절전/최대절전은 해제하는 것을 권장합니다.
- SQLite DB 파일 위치: %LOCALAPPDATA%\SaenaeOrderManager\orders.sqlite3
- 정기적으로 위 DB 파일을 백업하세요.
- 현재 버전은 사내 신뢰 LAN 전용의 초기 버전입니다. 인터넷에 포트 포워딩하지 마세요.

[자동 실행]
프로그램 상단의 'Windows 로그인 시 자동 실행'을 체크하고 '설정 저장'을 누르면
현재 Windows 사용자 계정의 로그인 시작 프로그램에 자동 등록됩니다.
해제하려면 체크를 끄고 다시 '설정 저장'을 누르세요.
메인 서버 PC에서도 이 옵션을 켜두면 로그인 후 프로그램이 자동 실행됩니다.
※ Windows 부팅 직후가 아니라 해당 사용자 로그인 시 실행됩니다.

[제한/후속 개선 권장]
- 초기 버전은 로그인/사용자별 권한 및 변경 이력 기능이 없습니다.
- 같은 발주를 여러 PC에서 동시에 수정하면 마지막 저장 내용이 반영됩니다.
- 네트워크 장애 시 입력한 데이터는 서버에 저장되지 않으므로 연결 상태 확인 후 등록하세요.
- 운영 배포 전 실제 사내 PC 2~3대에서 테스트하고 백업/복구 절차를 확인하세요.
